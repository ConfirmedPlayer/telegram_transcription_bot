# Changelog

Все заметные изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Краткая сводка голосовых, аудио и видео с заголовком и ответом на исходное сообщение
- Память разговора на 15 минут: сводка учитывает предыдущие реплики и их авторов
- Команды `/reset` и `/status`
- Основной и резервный бесплатные провайдеры сводки (Cerebras, Groq)
- Добавлена кнопка "Brief" для генерации структурированного брифа/ТЗ из текста
- Добавлен новый стиль обработки текста для создания брифов
- Реализована автоматическая структуризация текста по разделам

### Removed
- Расшифровка больше не отправляется в чат — бот присылает только сводку. На сообщения короче
  порога сводки (`SUMMARY_MIN_WORDS`, по умолчанию 100 слов), с нераспознанной речью и при сбое
  провайдеров бот не отвечает; заглушка «Обрабатываю видео...» в этих случаях удаляется

### Fixed
- Лог пишется в смонтированный том `logs/`

### Technical
- Создан новый промпт brief.md для обработки текста
- Обновлена структура клавиатуры стилей для поддержки нового формата
